# Fluxos de Negócio

## 1. Fluxo principal

`Candidatura do Artista -> Avaliação -> Aprovação -> Proposta de Guest -> Confirmação -> Captação -> Fechamentos -> Agenda -> Execução -> Finalização`

## 2. Studio

`Cadastro -> Avaliação -> Aprovação -> Disponibilidade -> Solicitação -> Aceite/Recusa -> Confirmação pela Assessoria -> Uso`

## 3. Fechamento

`Lead -> Negociação externa -> Recebimento dos 20% pela Assessoria -> Fechamento -> Agendamento confirmado`

## 4. Logística

`Guest confirmado -> Organização de viagem e acomodação -> Atualização pela Assessoria -> Acompanhamento em Minha Viagem`
