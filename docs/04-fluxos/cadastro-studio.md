# Fluxo de Cadastro do Studio

## 1. Objetivo

Controlar a entrada de Studios parceiros.

## 2. Fluxo principal

`Cadastro -> Perfil, estrutura, preços e disponibilidade -> Solicitação -> Avaliação da Assessoria -> Aprovado ou Reprovado`

## 3. Pós-aprovação

Somente após aprovação o Studio aparece nas pesquisas e pode integrar Guests.
