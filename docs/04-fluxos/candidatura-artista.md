# Fluxo de Candidatura do Artista

## 1. Objetivo

Controlar a entrada de Artistas na assessoria.

## 2. Fluxo principal

`Cadastro -> Preenchimento de dados e portfólio -> Envio -> Em análise -> Aprovado ou Reprovado`

## 3. Responsável pela decisão

Assessoria, por avaliação humana.

## 4. Exceções e pontos em aberto

- Dados mínimos obrigatórios.
- Solicitação de revisão.
- Comunicação do motivo da reprovação.
