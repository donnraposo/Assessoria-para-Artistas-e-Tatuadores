# Fluxo de Confirmação do Guest

## 1. Pré-condições

Proposta pronta, com os dados confirmatórios definidos.

## 2. Fluxo

`Proposta confirmada -> Guest confirmado -> Em captação -> Agenda completa -> Em andamento -> Finalizado`

Saída excepcional: `Cancelado`.

## 3. Efeitos

- Habilitar operação de marketing e agenda.
- Disponibilizar `Minha Viagem`.
- Permitir continuidade da organização logística.
