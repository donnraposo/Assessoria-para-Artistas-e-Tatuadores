# Fluxo de Proposta de Guest

## 1. Objetivo

Planejar uma operação antes de confirmá-la.

## 2. Estados

`Rascunho -> Em planejamento -> Pronta para confirmação -> Confirmada`

Saídas: `Recusada` ou `Cancelada`.

## 3. Dados para confirmação

Cidade, datas, Studio, Ads, valores das tattoos e moeda principal.

## 4. Observação

Viagem e acomodação podem continuar em organização após a confirmação.
