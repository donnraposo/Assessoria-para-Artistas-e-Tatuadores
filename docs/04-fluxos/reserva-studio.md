# Fluxo de Reserva de Studio

## 1. Fluxo pela plataforma

`Pesquisa -> Solicitação da Assessoria -> Aceite ou recusa do Studio -> Confirmação da Assessoria -> Reserva confirmada`

## 2. Fluxo externo

`Negociação externa -> Registro manual pela Assessoria -> Reserva confirmada`

## 3. Regras

- Considerar local, data, horário e capacidade.
- Impedir conflitos para o Artista.
- Pagamento externo pelo Artista com status `Pendente` ou `Pago`.

## 4. Pontos em aberto

- Validação final do pagamento e estados adicionais.
